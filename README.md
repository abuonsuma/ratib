# Ratib

Multi-tenant client job portal and ERP for printing and creative businesses in Ghana.

**Status: Phase 2.** Client portal (registration, guided job submission with drafts and private uploads, live tracking, alerts, email preferences) and a staff dashboard (role-based visibility, assignment, a gated workflow engine, internal notes, finished-file delivery, email alerts through a queue). Quotations, online approval, Paystack payments and reports follow in Phases 3 and 4.

- `docs/ARCHITECTURE.md`: design, schema, flows, phases
- `docs/SETUP.md`: run it locally, test it, deploy it
- `supabase/`: migrations, seed data, security tests
- `apps/web/`: Next.js application
